# Expense Tracker – Java Console Application

A simple **Java-based console application** for managing daily expenses. It allows users to add, view, edit, delete, and track expenses with organized records and summaries.
## Technologies Used
* Java
* OOPs
* Collections Framework
* File Handling
* Java Streams
## Key Features
* Add and manage expenses
* View and search expense records
* Edit and delete expenses
* Categorize expenses
* Generate expense summaries
